## 2. Tại sao
Bảng tương thích chính thức của Spring Cloud AWS chưa ghi Boot 4.1, và thiết kế ban đầu đặt cược vào điều đó. **Lúc này phát hiện vấn đề chỉ tốn 30 phút. Để đến Phase 3–4 mới phát hiện thì tốn cả tuần.** Smoke test đã bắt được 2 lỗi mà đọc tài liệu không thể thấy: model Haiku 5.5 không gọi được, và SDK cần module `signin` để đọc credential của `aws login`.

## 3. Kiến thức cốt lõi
- **BOM và `dependencyManagement`:** BOM chỉ *khai báo version*, không *thêm* dependency nào. `<scope>import</scope>` gộp danh sách version của BOM vào project. Nhờ vậy, khi thêm `spring-cloud-aws-starter-sqs` sau này thì không cần ghi version, và các module cùng họ luôn khớp version với nhau.
- **Maven giải quyết xung đột theo "nearest wins":** bản gần project nhất trong cây dependency sẽ thắng. Vì vậy cần `dependency:tree` để biết thực tế thư viện nào được dùng, không chỉ là thư viện nào được khai báo.
- **Default credentials provider chain:** SDK lần lượt thử system property → biến môi trường → web identity → profile (`~/.aws`) → container → IMDS. Trên ECS sẽ dùng nguồn *container* (task role); ở local dùng *profile*. Code không cần biết đang chạy ở đâu.
- **Inference profile và quyền truy cập model** là hai việc khác nhau: `list-inference-profiles` chỉ cho biết model *tồn tại*, chỉ gọi thật mới biết account có *được phép* hay không.

## 4. Cách khác & trade-off
| Cách | Trade-off |
|---|---|
| Thêm luôn các starter vào `jars-api` | Nhanh, nhưng app phải có AWS credential ngay cả khi chỉ chạy test |
| Chỉ đọc bảng tương thích, không test | Tiết kiệm 30 phút, nhưng sẽ bỏ sót cả 2 lỗi trên |
| Commit app smoke vào repo | Tái lập được dễ, nhưng test cần AWS thật thì không chạy trong CI được; ghi lại trong ADR là đủ |

## 5. Lỗi hay gặp
- Tin rằng "có trong danh sách" là "dùng được" (đúng chuyện của Haiku 5.5).
- Đặt `spring.config.import=aws-...` trong cấu hình chung, khiến mọi test đều cần AWS.
- Quên dọn tài nguyên tạm: secret bị tính $0.40/tháng và nằm đó mãi. Ở đây đã xóa bằng `--force-delete-without-recovery`.
- Dùng Git Bash với tên bắt đầu bằng `/`: MSYS tự đổi thành đường dẫn file.
